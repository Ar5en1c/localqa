LocalQA v0.1 alpha
====================

Local evidence + memory layer for frontier coding agents.
Frontier model plans and implements. LocalQA collects, compresses, remembers, and verifies local evidence.
Initial alpha uses Bonsai as the local worker model for evidence triage, cleanup, memory, and handoff prep.

Safe claim: LocalQA helps frontier coding agents use less context by collecting, compressing, remembering, and verifying local evidence before reasoning or implementation.
Model split: Bonsai handles local evidence work; the frontier model remains responsible for planning and implementation.
Caveat: It does not replace frontier models, intercept pasted cloud prompts, or prove patch correctness.
