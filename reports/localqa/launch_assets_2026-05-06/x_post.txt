Have you thought about giving Claude/Codex/OpenCode its own free local agent?

Not another coding model.
A helper agent for your main agent.

I built LocalQA for this.

It is a local Bonsai-backed sidecar that handles the noisy work around coding agents:

- logs
- browser evidence
- repo context
- project memory
- context cleanup
- handoff redaction

The frontier model still plans and writes code.
LocalQA handles local evidence and returns compact verified context.

Two ways to use it:

1. MCP server: portable default
2. OpenCode plugin: deeper workflow with tools, rules, hooks, and vault handles

Launch proof:

- 53.39% fewer fresh input tokens in one real OpenCode provider telemetry A/B test
- 74.04% reduction in controlled A/B workflow benchmark, 3/3 quality gates maintained
- 302,772 -> 8,842 tokens in long-horizon benchmark, 9/9 quality gates, 9/9 memory writes

Repo: https://github.com/Ar5en1c/localqa

Boundary: this does not replace frontier models or intercept text pasted directly into cloud chat.
