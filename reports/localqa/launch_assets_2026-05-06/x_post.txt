Launching LocalQA v0.1 alpha.

Agent for your agents.

A local Bonsai-backed sidecar that helps frontier coding agents handle logs, browser evidence, project memory, and context cleanup before spending cloud tokens.

MCP-first, with an OpenCode plugin for deeper workflows.

The frontier model still plans and writes code.
Bonsai handles noisy local evidence and returns compact verified context.

Launch proof:
- 53.39% fewer fresh input tokens in one real OpenCode provider telemetry A/B test
- 74.04% reduction in controlled A/B workflow benchmark, 3/3 quality gates maintained
- 302,772 -> 8,842 tokens in long-horizon benchmark, 9/9 quality gates, 9/9 memory writes

Repo: https://github.com/Ar5en1c/localqa

Not a frontier-model replacement. A local helper layer for better agent context.
